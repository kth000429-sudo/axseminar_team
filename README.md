# 마케팅 프로그램 신청 대시보드

CSV 신청 건을 7개 지점 권역에 따라 배분하고 누적 대시보드와 지점별 메일 초안을 제공합니다.

## 실행

1. Windows에서 `run.bat`을 더블클릭합니다. Python 3.10 이상이 필요합니다.
2. 실행할 때마다 신청 데이터, 메일 발송 이력, 권역 변경 내역이 초기화된 뒤 브라우저에서 Streamlit 앱이 열립니다. 한 번 실행한 세션 안에서는 이 데이터가 계속 누적됩니다. 터미널 창을 닫으면 앱이 종료됩니다.
3. OpenAI 초안 생성 및 실제 SMTP 메일 발송을 사용하려면 `.env.example`을 `.env`로 복사해 설정합니다. 기존 `OPENAI_API_KEY.env`의 OpenAI 키도 자동으로 읽습니다.

```env
OPENAI_API_KEY=...
SMTP_HOST=...
SMTP_PORT=587
SMTP_USER=...
SMTP_PASSWORD=...
SMTP_FROM=...
```

OpenAI 초안 생성은 `gpt-6-luna` 모델을 사용합니다. 실제 발송은 배분 페이지에서 수신자 주소를 확인하고 발송 확인란을 선택한 후 버튼을 눌러야 합니다. `example.com` 데모 주소로는 발송할 수 없습니다.

**권역 설정** 페이지에서 전국 시·군·구의 현재 담당 지점을 확인하고 클릭해 수정할 수 있습니다. 저장한 변경은 이후 신규 CSV 배분에 적용됩니다. 지도 경계 출처는 `data/지도_출처.txt`를 참고하세요.

기본 배분표는 `data/region_assignments.json`에 있으며, 전국 250개 시·군·구를 모두 포함합니다. 권역은 지점·권역의 인접성을 우선으로 정하고, 경계 지역은 주민등록 인구와 담당 지역 수를 보조 기준으로 조정했습니다. 기준 인구와 추정치는 `data/region_population.json`에 있습니다. 지도에서 저장한 임시 변경은 `run.bat` 실행 시 초기화되고 이 기본표로 돌아갑니다.

기본표 생성 로직은 `scripts/build_region_assignments.py`에 있습니다. 원본 인구 가중치 스냅샷은 `data/population_source.json`입니다.

## 예시 신청 데이터

프로젝트 폴더의 `더미_신청_10건.csv`와 `더미_신청_100건.csv`는 배분 흐름을 확인할 때 업로드할 수 있습니다. 신청 지역은 현재 저장된 기본 권역과 지도에서 수정한 권역을 반영해, 지점별 담당 인구와 시·군·구 인구 가중치로 생성합니다. 업로드할 때 배정 지점도 최신 권역 설정으로 다시 계산합니다. 신청일은 특정 주에 더 몰리도록 생성하며, 인입채널은 `맞춤정보/마케팅/캐시백미션/외부광고` 가중치 55:25:15:5를 따릅니다. 소개 페이지의 10건 미리보기와 CSV 다운로드만으로는 누적 데이터에 저장되지 않습니다. 예시를 실제 배분 과정처럼 확인하려면 CSV를 업로드하고 **신규 배분 저장**을 눌러야 대시보드에 반영됩니다.

실제 메일 발송에는 사용자의 SMTP 서버 정보가 필요합니다. 프로젝트 `.env`에 저장하거나 배분 페이지의 **SMTP 발송 설정** 폼에서 현재 실행 세션에 입력한 뒤, 실제 수신 주소와 발송 확인란을 검토하면 버튼이 메일을 전송합니다. 세션 입력값은 프로젝트 파일에 기록되지 않습니다. 포트 465는 SSL, 그 외 포트는 STARTTLS로 연결하며, 예약 도메인 `example.com` 주소는 발송할 수 없습니다.

## SMTP 입력 안내

배분 페이지에서 계정 이메일의 @ 앞 아이디를 입력하고 @ 뒤 도메인을 선택합니다(Gmail, 네이버, 다음/한메일, Outlook, 직접 입력). 포트 도움말은 Google Gmail 587(STARTTLS)/465(SSL), 네이버 587(TLS)/465(SSL) 예시를 안내합니다. 앱 비밀번호는 16자를 4칸에 나누어 입력하며, 한 칸이 채워지면 다음 칸으로 이동합니다. 발신 이메일은 계정 이메일이 기본값이고 별도 수정할 수 있습니다. 입력값은 현재 실행 세션에서만 유지됩니다.

## CSV 열

- 필수: 신청자 이름, 신청일자, 인입채널, 신청 광역시도, 신청 시·군·구
- 인입채널 허용값: `맞춤정보`, `마케팅`, `캐시백미션`, `외부광고`
- 선택: 신청번호
- 한 열로 지역을 제공하는 경우 `신청지역`에 `서울특별시 강서구`처럼 광역시도와 시·군·구를 함께 입력합니다.

분석 결과는 CSV로 다운로드할 수 있습니다. 누적 신청 및 발송 이력은 `data/`에 저장됩니다.

## 화면 디자인

선택된 B안(클린 블루 & 여백)을 전체 화면에 적용합니다. 밝은 블루 내비게이션, 진한 남색 본문과 숫자, 선명한 블루 강조, 평면형 흰색 카드와 고대비 그래프를 사용합니다. 모바일 화면에서는 카드와 제목 크기를 조정합니다.
